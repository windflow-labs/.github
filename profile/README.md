# Windflow Labs

Windflow runs realtime interactive AI video models as on-demand sessions. Teams plug them into their products and pay by the session second.

This is the official Windflow Labs organization for **[windflow.online](https://windflow.online)**, the developer platform for realtime video and interactive world models. Sessions receive supported prompts, images, camera tracks or actions and stream generated output. Model authors retain credit and their models retain their own licenses.

## Build and explore

- **[Realtime browser examples](https://github.com/windflow-labs/realtime-examples):** plain JavaScript examples for Helios, LongLive, SANA-Streaming and LingBot, with a local token server and explicit session cleanup. MIT example code; approved private-beta API access is required for live use.
- **[World Model Directory](https://github.com/windflow-labs/world-model-directory):** source-linked controls, weight-license declarations, author realtime claims and places to try. Models and providers are listed alphabetically; inclusion does not establish Windflow hosting or current capacity.
- **[Public API guides](https://windflow.online/guides):** integration, model selection, session lifecycle and measurement boundaries.
- **[Model catalog](https://windflow.online/models)** and **[pricing](https://windflow.online/pricing):** Windflow service profiles, inputs, controls, rates and access requirements.

## Access and official links

Windflow is in private beta. [Request access](https://windflow.online/auth?mode=request) or contact [hello@windflow.online](mailto:hello@windflow.online). Capacity is brought up on demand; a catalog listing does not mean a GPU is always running. Billing starts at the first generation_started event and stops at release or session end; queueing and startup are free. Read the current pricing page before integration.
